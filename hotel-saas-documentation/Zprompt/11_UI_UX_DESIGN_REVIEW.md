# Prompt 11 — UI/UX Design System and Screen Review

Read `06-ui-ux/UI_UX_GUIDELINES.md` and the PRD. Audit the current screens and build a consistent design system for:
1. SaaS operator console.
2. Hotel owner/manager dashboard.
3. Reception room and stay workspace.
4. Staff task inbox/PWA.
5. Guest QR portal.

For every screen, specify user goal, hierarchy, responsive behavior, loading/empty/error/success states, permissions, accessibility and key actions. Keep guest screens minimal and admin screens information-rich. Use tenant branding only in the guest-facing and appropriate hotel areas. Do not create decorative UI without working behavior. Provide screenshots or a screen inventory in the implementation report.
