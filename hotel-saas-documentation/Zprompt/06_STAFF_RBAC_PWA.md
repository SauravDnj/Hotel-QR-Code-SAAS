# Prompt 06 — Staff Accounts, RBAC and PWA

Read RBAC, security, UI/UX and PRD. Implement:
- Staff invitation/create/deactivate.
- Membership, role, permission and department assignment.
- Property and department-scoped access.
- Default roles: owner, manager, receptionist, housekeeping, room service, maintenance, security, custom.
- Central server authorization helper.
- Staff mobile PWA shell and install metadata.
- Staff profile and notification preferences.
- Role/permission management UI.
- Automated allow/deny permission matrix tests.

Do not rely on UI hiding. Every server operation must authorize.
